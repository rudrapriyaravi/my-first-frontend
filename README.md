
# My First Frontend Project

A simple and beginner-friendly personal profile webpage built using HTML, CSS, and JavaScript.

## Project Overview

This project displays a basic personal profile with a welcome message and an interactive button. It is created to practise frontend development and understand GitHub collaboration workflows.

## Technologies Used

- HTML5 – Webpage structure
- CSS3 – Styling and layout
- JavaScript – Button interaction

## Project Structure

```text
my-first-frontend/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## Features

- Simple personal profile webpage
- Clean and minimal user interface
- Interactive button using JavaScript
- Basic responsive layout

## How to Run

1. Clone this repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```
2. Open the project folder.
3. Open `index.html` in your browser.

## GitHub Concepts Practised

- Creating repositories
- Creating feature branches
- Making commits
- Pushing code changes
- Creating Pull Requests
- Reviewing and merging Pull Requests

## Purpose

This project is created for learning basic frontend development and practising Git and GitHub version control workflows.
